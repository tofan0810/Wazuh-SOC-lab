## 🚀 SUMMARY OF KEY UPGRADES (WHAT WAS UPDATED)

Compared to the original SOAR release (which supported only one-way IP blocking), this update incorporates 4 strategic capabilities:

1. **Closed-Loop Process & Self-Healing (1-Click Rollback):**
   - Upon isolating or blocking an IP, Telegram automatically generates a **`[🟢 Unblock IP (Rollback)]`** button.
   - Instantly restores service in under 5 seconds in false-positive scenarios without requiring manual host access.

2. **Host-Level Eradication Expansion (Endpoint Eradication):**
   - **`[🛑 Kill Process]`**: Immediately terminates malicious processes (`Stop-Process -Force`), severing the attacker's interactive session.
   - **`[🧹 Clean Persistence]`**: Automatically cleans up Registry Run Keys (`HKCU:...\CurrentVersion\Run`) and UAC Hijacking configurations (`HKCU:...\Classes\ms-settings`).
   - **`[🔒 Isolate Host]`**: Isolates the host from Kali and external networks while **preserving WinRM (5985) and Wazuh Agent (1514)** channels to maintain management connectivity.

3. **Feedback Storm Elimination:**
   - Cleans up duplicate `<integration>` blocks in `ossec.conf`, removing the deprecated `custom-telegram` integration.
   - Implements a **Hierarchical Child Rule Model (Rule 100008 Level 0)** to automatically suppress alerts generated by `socrunner` remediation actions executed via CMD/WinRM.
